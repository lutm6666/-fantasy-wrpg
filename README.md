# 灰燼王境 Ashen Realms

行動裝置優先的中古奇幻文字 WRPG 專案。

## 目前版本 v0.1

第一版採單一 `index.html`，目標是讓 iPhone Safari 可以直接載入與遊玩，不依賴框架或外部套件。

目前已有：

- 6 種初始職業：戰士、聖騎士、遊俠、盜賊、法師、牧師
- 等級、經驗、生命、攻擊、防禦與金幣
- 裝備欄、背包、消耗品與任務物品
- NPC 對話與隱藏式選項結果
- 任務與線索系統
- 回合制戰鬥與職業技能
- 第一個任務「鐘塔下的失蹤者」
- 第一個地下城入口「舊鐘塔」
- LocalStorage 自動存檔
- 行動裝置 UI

## 設計方向

系統層借鑑 MMORPG 的職業、專精、裝備、地下城、Boss、掉落與成長結構；探索與 NPC 互動偏向開放式 WRPG；任務則強調調查、選擇與延遲後果。
