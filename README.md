# Ashen Realms · 灰燼王境

手機優先的中古奇幻文字 WRPG。遊戲採用職業、等級、裝備、地下城與首領等角色成長系統，並以分支任務、NPC 互動、調查與派系選擇作為敘事核心。

## v0.2 — 種族與鐘塔更新

- 7 個可選種族：人類、高等精靈、森林精靈、矮人、獸人、獸裔、不死族（灰裔）
- 種族 × 職業限制系統
- 4 個種族專屬職業：魔劍士、符文守衛、祖靈使、墓誓者
- 不死族專屬對話與世界互動
- v0.1 存檔自動遷移
- 修正舊鐘塔「腐化鼠群」重複刷新問題
- 擴建鐘塔地窖：囚籠區、裂眼祭壇、菁英戰與首領「鐘下守衛」
- 新增第一批場景圖片整合架構；圖片失敗時會自動隱藏，不影響遊戲

## 執行

專案為純靜態網頁，可直接使用 GitHub Pages。入口為 `index.html`，樣式與邏輯分別位於 `styles.css`、`game.js`。

## 後續方向

持續擴張灰港、派系、裝備品質與隨機詞綴、技能／專精、更多種族專屬劇情，以及新的野外區域與地下城。
